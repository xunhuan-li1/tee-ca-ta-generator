# GP Project Generator

A CA / TA project generator for Windows. Select features and enter parameters to generate the corresponding source code and build configuration.

- **CA**: A client application running in the normal operating system that sends requests to a TA.
- **TA**: A program running in a trusted execution environment that handles cryptographic operations, secure storage, and other tasks.

The program defaults to English and can be switched to Chinese. It supports both a graphical interface and AI-driven project generation through the command line.

## Features and GP Specification Scope

The generated code supports the following GlobalPlatform documents:

1. **TEE Internal Core API Specification v1.3.1**
2. **TEE Client API Specification v1.0**
3. **TEE Client API v1.0 Errata and Precisions v2.0**

Peripheral and event APIs (Core Chapter 9), diagnostic examples, and legacy compatibility APIs are excluded.

Whether generated features can run on a device depends on the target TEE's implementation and configuration. The project has passed compilation and runtime tests in OP-TEE 4.10.0 QEMU. These tests exclude GP features that OP-TEE does not support.

The following features can be generated:

- Digest, encryption/decryption, MAC, signing and verification, key agreement, and key derivation examples, including algorithms such as AES, RSA, SM2, SM3, and SM4.
- Property queries, secure storage, random numbers, time, memory, big integers, and session communication examples.
- Keys generated by the TA or supplied by the CA, with algorithm-specific settings such as IVs, messages, and tag lengths.
- A CA configured as an executable, shared library, or static library, or a TA-only project.
- Utilities for calculating SM2 ZA and pre-signature digests, viewing and converting certificates, extracting public keys, and calculating fingerprints.

## Quick Start

Download the [Windows x64 single-file application](GP-Project-Generator-win-x64/GP-Project-Generator.exe) and double-click it to run. Python and the .NET SDK are not required. You can also download the entire repository and run the program in `GP-Project-Generator-win-x64/` directly.

Workflow:

1. **Define project**: Enter the name, UUID, and version, and select the CA output type.
2. **Choose features**: Add features, select algorithms, and enter parameters.
3. **Review & export**: Preview the source code and choose an export location.
4. **Build and run**: Follow the generated project's `README.md` to prepare the development environment, build, and deploy the CA / TA.

For example, select AES-CBC encryption/decryption and SHA-256 digests, then choose an executable CA to generate a project containing both features. Running the compiled CA without arguments executes all selected features in sequence.

## Generate Projects with AI

Give [AI_GUIDE.md](AI_GUIDE.md) and the program path to an AI assistant that can read local files and execute commands, then describe your requirements in natural language. The AI creates a JSON configuration, validates it, and invokes the generator to export source code. Graphical interface users do not need to write JSON manually.

Example prompts:

> Read AI_GUIDE.md and use GP-Project-Generator.exe in the current directory to generate an AES-CBC encryption/decryption and SHA-256 digest project. Supply the key and IV from the CA and build the CA as a shared library. Validate the configuration first, then export to generated/demo.

> Read AI_GUIDE.md and generate an SM2 signing and verification project. Generate keys in the TA, include the ZA calculation function, and build the CA as an executable. Tell me where the files are, how to build them, and which checks have been completed.

The program provides three commands to query available features, validate configuration, and generate source code:

```text
GP-Project-Generator.exe --describe catalog.json
GP-Project-Generator.exe --validate project.json validate-report.json
GP-Project-Generator.exe --generate project.json generated generate-report.json
```

When invoking the program from PowerShell, wait for the process to exit. See the AI guide for complete examples.

## Build from Source

Install the **.NET 10 SDK** on Windows, then run the following in the repository directory:

```powershell
.\build.ps1 -SingleFile
```

The program is generated at `release-single/GP-Project-Generator.exe`. If the SDK is not on PATH, specify its location:

```powershell
.\build.ps1 -SingleFile -DotnetPath 'C:\tools\dotnet\dotnet.exe'
```

The SDK is only needed to build the generator, not to run the single-file EXE. When distributing the program, include the licenses and third-party notices from the build output.
